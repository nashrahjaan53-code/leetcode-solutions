## Overview

A personal collection of LeetCode solutions written in Python, maintained as a log of consistent practice and continuous improvement.

---

## Purpose

- Practice coding problems regularly
- Strengthen algorithmic thinking and problem-solving skills
- Track personal progress over time
- Prepare for technical interviews

---

## Language

Python 🐍

---

## Repository Structure

Each file represents a single problem solution, named after the problem for easy reference:

- `two-sum.py`
- `valid-parentheses.py`
- `binary-search.py`

---

## Approach

For each problem, I aim to:

- Start with a brute-force solution to build understanding
- Optimize for time and space complexity where possible
- Write clean, readable code without unnecessary complexity

Solutions may be revisited and improved over time as my understanding deepens. This repository is purely for learning purposes.
